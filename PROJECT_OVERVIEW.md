# Personal Book Recommender

## Project Overview

Personal Book Recommender is a Streamlit application that recommends books based on a selected title. It combines collaborative-filtering data, a precomputed similarity matrix, and an interactive interface to provide personalized suggestions.

## Features

- Browse popular books.
- Select a book from the recommendation interface.
- Generate the five most similar books.
- Display book metadata and cover images.
- Explore the underlying datasets.

The application uses Python, Streamlit, Pandas, NumPy, and serialized model artifacts with cosine-similarity results prepared in advance.
